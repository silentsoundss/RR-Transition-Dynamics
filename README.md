# RR-Transition-Dynamics
This repository is meant to accompany my honors thesis being completed at UCLA. The goal is to examine transition dynamics in the context of misallocation. I replicate and extend the following paper:

Restuccia, D. and Rogerson, R. (2008). Policy distortions and aggregate productivity with heterogeneous establishments. Review of Economic Dynamics, 11(4):707-720.
